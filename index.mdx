CrashWOC Decomp PS2 is a work-in-progress decompilation of **Crash Bandicoot: The Wrath of Cortex** for the PlayStation 2. The goal is a clean-room reconstruction of the retail executable — hand-written C that compiles byte-for-byte to the original `SLES_503.86` binary. No game assets are stored in this repository; contributors supply their own legally-obtained copy of the game.

## Get Started in 3 Steps

<Steps>
  <Step title="Supply your game files">
    Place your legally-obtained copy of the PAL retail disc at `orig/pal103/`. Two files are required: `SLES_503.86` (6,731,763 bytes) and `SYSTEM.CNF`. Both are verified against locked SHA-256 hashes before any work begins.
  </Step>
  <Step title="Build the toolchain and workspace">
    Run `python decomp.py toolchain` to pull the container image, install the locked EE GCC compilers, and verify every binary fingerprint. Then run `python decomp.py setup` to split the ELF, build per-unit objects, and generate the objdiff report.
  </Step>
  <Step title="Open objdiff and start matching">
    Open the repository in the [objdiff GUI](https://github.com/encounter/objdiff) for live per-function match feedback. Pick a unit, write C in `src/<group>/<unit>.c`, and run `python decomp.py src/<group>/<unit>.c` to rebuild and see your match percentage.
  </Step>
</Steps>

## Target Build

All matching work targets exactly one build:

| Field | Value |
|---|---|
| Title | Crash Bandicoot: The Wrath of Cortex |
| Region | PAL retail v1.03 |
| Serial | SLES-50386 (`SLES_503.86`) |
| Size | 6,731,763 bytes |
| SHA-256 | `7fc6826d…26b1eca1` |

<Note>
  This repository contains no game assets, no game code, and no copyrighted binaries. Game files must be supplied by the contributor from their own copy.
</Note>

## Key Features

<CardGroup cols={2}>
  <Card title="Dual-Compiler Toolchain" icon="microchip">
    Two locked compilers — SN ProDG EE GCC 2.95.2-EE for game TUs and Sony EE GCC 2.9 for the runtime — matching the exact compilers used by the original developers.
  </Card>
  <Card title="Hybrid Object System" icon="object-group">
    Each translation unit compiles as a hybrid: verified matching C for proven functions, original retail assembly for the rest. Every link is byte-gated.
  </Card>
  <Card title="Full Symbol Registries" icon="database">
    3,751 functions and 3,750 data symbols extracted directly from the retail `.mdebug` ECOFF debug section — no guessing, no hand-crafting.
  </Card>
  <Card title="AI-Assisted Workflow" icon="wand-magic-sparkles">
    The MCP server exposes ranked candidates, context, compile/diff, and promotion to any standards-compliant AI agent. Sessions are shared across clients.
  </Card>
</CardGroup>
